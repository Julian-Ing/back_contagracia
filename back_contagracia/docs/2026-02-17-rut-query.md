# RUT Query - Electronic Documents

**Fecha:** 2026-02-17

## Resumen

Endpoint público para consultar información de terceros (NIT) en la DIAN. Se usa en:
- Form de registro de empresa
- Form de creación/edición de terceros (clientes, proveedores)

Implementado en frontend Next.js para rellenar automáticamente datos del tercero.

## Endpoint

**`POST /dian/query-rut`** (público)

Consulta información del tercero por NIT en la API DIAN.

**Body:**
```json
{
  "identification_number": "123456789"
}
```

**Response (éxito):**
```json
{
  "success": true,
  "message": "...",
  "data": {
    "business_name": "EMPRESA EJEMPLO S.A.S.",
    "email": "info@empresa.com",
    "address": "Calle 123 #45-67",
    "phone": "601234567"
  }
}
```

**Response (error):**
```json
{
  "success": false,
  "message": "NIT no encontrado en DIAN"
}
```

## Uso

- **Frontend**: Sin autenticación (público)
- **No requiere JWT**
- Se llama desde forms de registro y creación de terceros
- Valida que el NIT exista antes de crear

## Configuración

Requiere:
- `DIAN_API_URL` en .env de electronic-documents-service
- `DIAN_API_TOKEN_RUT` en .env (token solo lectura para RUT)
